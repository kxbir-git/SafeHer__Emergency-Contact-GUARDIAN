# SafeHer Demo & Media Assets

Place demo videos and UI media assets in this directory.

- **Demo Video file path**: `docs/demo.mp4` (or `docs/demo.webm`)
- **Recommended recording specs**:
  - Resolution: 1920x1080 or 1280x720
  - Frame rate: 30 fps
  - Topics covered:
    1. Login with demo account (`demo@safeher.app` / `demo1234`)
    2. Hold SOS button for 3 seconds to trigger emergency broadcast
    3. View live GPS map and hazard markers
    4. Test Fake Call escape simulator
